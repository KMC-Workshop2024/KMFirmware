# KM 模块固件

KM 模块固件升级包的下载与更新说明。

- 升级包为加密文件（`KMModule-x.y.z.fw`），只能由 KM 模块读取，位于本页右侧的 **Releases**。
- 更新：KM Drive 连接模块后会自动检查固件更新，有新固件时显示版本号和更新内容，由用户确认后升级。也可以在软件的「设备与升级」页点「检查固件更新」。
- 先更新软件，再更新固件。固件需要较新的软件时，软件会提示先更新软件。
- 更新记录：见 [CHANGELOG.md](CHANGELOG.md)。

本仓库只存放加密的升级包和更新说明，不含源码。
